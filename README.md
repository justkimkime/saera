# SAERA · 새라

> 새로운 여행지를 찾고, 나의 속도와 취향에 맞는 여행을 준비하는 여행 안내 누리집

**시연 사이트:** [새라 바로가기](https://saera-seven.vercel.app/)

## 프로젝트 소개

새라는 ‘새롭다’는 뜻을 담아, 새로운 여행지를 쉽고 간편하게 찾을 수 있도록 만든 여행 안내 누리집입니다. 한국관광공사 관광정보를 활용해 일반 여행지뿐 아니라 무장애 여행, 반려동물 동반 여행, 웰니스 여행 정보를 제공합니다.

가보고 싶은 여행지를 찜하고, 최대 7일간의 일정에 담아 방문 순서를 정할 수 있습니다. 지도에서 위치를 확인하고 날짜별로 메모를 남기며, 여행지 탐색부터 일정 준비까지 이어지는 경험을 제공합니다.

로고는 새라의 한글 자음 ‘ㅅ’과 ‘ㄹ’로 산과 강을 표현하고, 따뜻한 색으로 여행의 설렘과 편안함을 담았습니다.

## 기획 배경

여행지를 고를 때는 지역과 관심사뿐 아니라 동행과 이동 여건도 고려해야 합니다. 찾은 장소를 따로 기록하고 지도에서 다시 확인해야 하는 과정도 번거롭습니다. 이 프로젝트는 다음 질문에서 시작했습니다.

- 지역·현재 위치·검색어 등 다양한 방식으로 여행지를 찾을 수 없을까?
- 접근성이나 반려동물 동반 조건에 맞는 여행 정보를 함께 살펴볼 수 없을까?
- 마음에 드는 장소를 저장한 뒤 날짜별 일정으로 자연스럽게 연결할 수 없을까?
- 한국어 사용자에게 필요한 정보를 충분히 제공하면서 다른 언어로도 확장할 수 없을까?

## 핵심 목표

1. 지역·주변·키워드 검색으로 여행지를 쉽게 찾는다.
2. 일반·무장애·반려동물 동반·웰니스 여행 정보를 제공한다.
3. 언어별로 실제 제공 가능한 콘텐츠와 메뉴를 표시한다.
4. 찜한 여행지를 날짜별 일정으로 정리하고 지도에서 위치를 확인한다.

## 주요 기능과 설계 의도

### 여행지 검색

- 지역, 주변, 키워드의 세 가지 검색 방식을 제공합니다.
- 검색 버튼을 누르거나 Enter를 입력하면 조회하며, 결과는 페이지당 10개씩 표시합니다.
- 처음 접속했을 때는 여행지 목록을 자동으로 조회하지 않아 불필요한 호출을 줄였습니다.
- 지역·주변 검색은 목록과 지도를 함께 확인할 수 있으며, 지도는 접거나 펼칠 수 있습니다.
- 상세 화면에서 돌아오면 현재 탭의 검색 조건·결과·페이지·스크롤을 복원합니다.

### 테마 여행

- 무장애 여행, 반려동물 동반 여행, 웰니스 여행을 별도 경로로 구성했습니다.
- 테마별로 지역·주변·키워드 검색을 제공하고, 해당 API가 지원하는 조건을 사용합니다.
- 상세 화면에서는 공통 장소 정보와 테마별 정보를 확인할 수 있습니다.
- 정보가 비어 있는 경우에는 확인이 필요함을 표시하고, 방문 전 시설에 문의하도록 안내합니다.

### 다국어 안내

- 한국어는 일반·무장애·반려동물 동반·웰니스 여행을 제공합니다.
- 영어는 일반·웰니스 여행을 제공합니다.
- 선택한 언어에서 지원하지 않는 메뉴는 숨기며, 지원하지 않는 화면에서 언어를 바꾸면 여행지 검색으로 이동합니다.
- 언어 선택은 현재 탭에서 새로고침해도 유지됩니다.
- 화면 문구는 하나의 JSON 파일에서 언어별로 관리하고, API의 언어 지원 정책은 별도 설정으로 분리했습니다.

### 여행지 상세

- 사진, 소개, 주소, 이용 안내와 위치를 확인할 수 있습니다.
- 제공되는 경우 홈페이지와 예약 안내 홈페이지를 새 창으로 연결합니다.
- API마다 다른 필드 이름을 화면에서 사용할 공통 정보로 변환합니다.
- 항목은 PC에서 두 열로 배치하고, 작은 화면에서는 한 열로 전환합니다.

### 찜한 여행지

- 검색 결과와 상세 화면에서 여행지를 찜할 수 있습니다.
- 찜 목록에서는 장소의 관광 유형과 저장한 여행 테마를 함께 표시합니다.
- 언어·서비스·콘텐츠 ID 등을 구분해 서로 다른 출처의 장소를 관리합니다.
- 저장한 여행지는 일정 관리 화면에서도 확인하고 날짜별 일정에 추가할 수 있습니다.

### 일정 관리

- 이름과 시작일·종료일을 지정해 최대 7일간의 일정을 만듭니다.
- 시작일은 오늘부터 선택할 수 있으며, 시작일을 선택해야 종료일 입력이 활성화됩니다.
- 종료일은 시작일을 포함해 7일 이내로 제한합니다.
- PC에서는 왼쪽 찜 목록에서 오른쪽 날짜별 일정으로 여행지를 끌어 추가할 수 있습니다.
- 드래그 외에도 날짜 선택 후 추가, 위·아래 이동, 다른 날짜로 이동하는 조작을 제공합니다.
- 찜 목록을 관광 유형별로 좁혀 보고, 카드와 지도에서 같은 번호로 장소를 확인할 수 있습니다.
- 날짜를 넘기며 당일 방문 순서를 확인하고 날짜별 메모를 작성합니다.
- 수정 내용은 확인 버튼을 눌렀을 때 저장되며, 취소하면 이전 저장 내용으로 돌아갑니다.

### 지도

- 카카오맵으로 검색 결과와 일정에 담은 장소의 위치를 표시합니다.
- 선택한 날짜의 여행지는 방문 순서에 맞춰 번호를 표시합니다.
- 좌표가 없거나 지도를 불러올 수 없는 경우에는 안내 문구를 표시합니다.

### 반응형과 접근성

- 화면 폭에 따라 검색 입력, 상세 정보, 일정 관리의 배치를 조정합니다.
- 버튼·링크의 용도를 구분하고, 탭과 입력 요소에 접근성 속성을 제공합니다.
- 드래그를 사용하기 어려운 환경을 위해 버튼과 날짜 선택으로 조작할 수 있는 대안을 마련했습니다.

## 실행 방법

Node.js 20.19 이상을 권장합니다.

```bash
npm ci
cp .env.example .env.local
```

`.env.local`에 환경변수를 설정합니다.

| 환경변수 | 용도 |
| --- | --- |
| `TOUR_API_KEY` | 공공데이터포털 Decoding 서비스키. 서버에서만 사용 |
| `VITE_KAKAO_MAP_APP_KEY` | 카카오맵 JavaScript 키. 브라우저 공개용 |

관광공사 서비스키 하나를 5개 서비스에서 공통으로 사용하되, 각 서비스의 활용 신청과 승인 여부는 별도로 확인해야 합니다. 카카오맵은 사용을 활성화하고 실제 개발·배포 주소를 SDK 도메인에 등록해야 합니다.

```bash
npm run dev
```

환경변수 변경 후에는 개발 서버를 다시 실행합니다.

프로덕션 빌드와 미리보기:

```bash
npm run build
npm run preview
```

## 코드 구성과 검증

화면은 페이지와 공통 컴포넌트로 나누고, 검색·언어·찜·일정 상태는 전용 훅으로 분리했습니다. 일정의 날짜 계산, 여행지 추가와 이동, API 응답 변환 등은 화면과 분리해 검증할 수 있도록 구성했습니다.

화면 문구와 API 언어 정책을 분리해 다른 언어를 추가할 때 변경 범위를 줄였습니다. 서버는 등록된 API와 파라미터만 허용하고, 관광공사 서비스키를 요청에 추가합니다.

```bash
npm test
npm run build
```

현재 자동 테스트는 40개이며, 주요 검증 항목은 다음과 같습니다.

- 서버 요청 검증, 서비스키 처리, 오류 응답
- 코드·검색 캐시의 재사용과 만료, 중복 요청 처리
- API 응답 형식과 홈페이지 주소 변환
- 일정의 날짜 범위, 중복 장소, 순서 변경과 날짜 간 이동
- 카카오맵 SDK 로딩과 좌표 검증
- 언어별 문구 키와 경로 접근 정책

## 데이터 저장 방식

회원가입 없이 사용할 수 있도록 찜한 여행지와 일정을 브라우저 `localStorage`에 저장합니다. 새로고침 후에도 유지되지만, 다른 브라우저나 기기와 자동으로 동기화되지는 않습니다. 브라우저 데이터를 삭제하면 저장 내용도 사라집니다.

일정에는 추가 당시의 장소 정보를 별도로 보관하므로 찜을 해제해도 일정의 여행지가 함께 삭제되지는 않습니다. 선택한 언어는 `sessionStorage`에 저장해 현재 탭에서 유지합니다.

지역 코드는 브라우저에 30일간 저장하고, 동일한 검색 조건·페이지는 현재 탭에서 10분간 재사용합니다. 이 캐시는 호출을 줄이는 장치이며 서버 전체의 일일 호출 상한을 보장하지는 않습니다.

## 배포와 환경 설정

관광공사 서비스키는 서버 환경변수로 관리합니다. Vercel에서는 저장소 루트에서 배포하고 `TOUR_API_KEY`와 `VITE_KAKAO_MAP_APP_KEY`를 등록합니다. `dist`만 GitHub Pages 같은 정적 호스팅에 올리면 `/api/tour` 서버 함수가 동작하지 않습니다.

카카오 JavaScript 키는 브라우저에서 사용하므로 공개되며, 등록 도메인으로 사용을 제한합니다. 관광공사 키에는 `VITE_` 접두사를 붙이지 않습니다.

실제 환경 파일, 의존성, 빌드 결과, 로컬 작업 자료와 API 테스트 도구는 `.gitignore`에서 제외합니다. 공개 앱에는 API 테스트 페이지가 포함되지 않습니다. 서버에서 사용하는 API 명세와 자동 테스트 코드는 저장소에 유지합니다.

## 향후 개선 방향

- **데이터 백업**: 찜 목록과 일정을 파일로 내보내고 다시 가져오는 기능으로 브라우저 변경과 데이터 삭제에 대비하고자 합니다.
- **기기 간 동기화**: 선택적인 로그인과 서버 저장을 통해 여러 기기에서 여행 준비를 이어갈 수 있도록 개선하고자 합니다.
- **지원 언어 확대**: API의 언어 지원 범위와 번역 문구를 확인하며 다른 언어를 추가하고자 합니다.
- **여행지 추천**: 계절과 지역을 바탕으로 여행지를 소개하는 화면을 구성하고자 합니다.
- **호출량 관리**: 서버의 요청 제한과 캐시를 보완해 공개 운영 시 호출량을 더 안정적으로 관리하고자 합니다.
- **접근성 검증**: 실제 모바일 기기와 보조 기술 환경에서 검색·메뉴·일정 조작을 지속적으로 점검하고자 합니다.
